# Bundled Cheats

These GateShark/CTRPF cheat files are bundled for the Android Cheat Advanced build and
copied into the selected Azahar user directory when the matching file is missing.

Existing non-empty user cheat files are not overwritten by the installer. If a bundled cheat is fixed here but the Thor still shows old content, remove or replace the on-device cheat file manually.

Performance-related cheat presets should be documented with the matching title profile when a game also needs Thor-specific settings.
